🧠 GAME AI — The Decision Loop
<div align="center">
text

   │   OBSERVE   │  ◄── world state
   └──────┬──────┘
          ▼
   ┌─────────────┐

   └──────┬──────┘

   ┌─────────────┐
   │   COMPARE   │  ◄── options
   └──────┬──────┘
          ▼
   ┌─────────────┐
   │ COORDINATE  │  ◄── other agents
   └──────┬──────┘
          ▼
   ┌─────────────┐
   │   DECIDE    │
   └──────┬──────┘
          ▼
   ┌─────────────┐
   │     ACT     │
   └─────────────┘

I'm especially interested in AI agents that don't simply know everything or follow one giant script.

I want agents that:

🧩 Have their own information

🎯 Evaluate situations

🔄 Reconsider actions

🤝 Cooperate with other agents

🎚️ Behave differently depending on difficulty

That makes game AI feel less like a scripted switch and more like a system of decisions.
